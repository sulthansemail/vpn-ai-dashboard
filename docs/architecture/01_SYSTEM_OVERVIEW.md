# System Overview

The Operations Platform consists of five logical layers.

------------------------------------------------------------

Layer 1

Business Systems

CRM

Payment Gateway

Website

Support Platform

------------------------------------------------------------

Layer 2

Synchronization Layer

CRM Sync Service

Payment Sync

Support Sync

Store Sync

------------------------------------------------------------

Layer 3

Operations Database

Stores all synchronized business data.

Stores monitoring data.

Stores AI outputs.

Optimized for dashboards.

------------------------------------------------------------

Layer 4

Intelligence Layer

Analytics Engine

Monitoring Engine

AI Engine

Recommendation Engine

Alert Engine

------------------------------------------------------------

Layer 5

Presentation Layer

Mission Control Dashboard

Infrastructure

Users

Business

Analytics

Operations

AI Center

------------------------------------------------------------

Principles

CRM owns transactions.

Operations Platform owns intelligence.

Monitoring is independent.

AI never modifies CRM records.

All recommendations are advisory unless explicitly approved.
