# UI Guidelines

This document captures the current UI direction for the operations platform.

## Core principles

- Mission Control should be concise and decision-focused.
- Data should be presented as operational signals, not raw database dumps.
- UI should support quick review and action prioritization.

## Layout

- Topbar and sidebar navigation are consistent across routes.
- Main view should contain structured cards and grids.
- Use section headings for business, infrastructure, and AI content.

## Visual rules

- Dark background with bright accent colors for status.
- Use clear labels and small supporting text.
- Reserve charts and trend lines for operational insight.
- Keep status badges and confidence indicators consistent.
