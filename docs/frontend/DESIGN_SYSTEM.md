# Design System

The frontend design system supports a professional internal operations dashboard.

## Visual style

- Dark theme by default
- Primary blue accent
- Rounded XL cards
- Generous spacing and clear hierarchy
- Minimal, professional, and functional

## Typography and layout

- Use clear headings and concise labels
- Keep panels simple and focused
- Use whitespace to separate distinct operational areas
- Avoid excessive decoration

## Components

- Use reusable presentational components
- Organize components by domain (layout, dashboard, intelligence, operations)
- Keep component size small and focused
- Avoid duplicate UI implementations

## Interaction patterns

- Sidebar navigation controls major product sections
- Mission Control is the primary landing experience
- Cards should surface prioritized operational signals
- Data tables are secondary; use them only when needed
