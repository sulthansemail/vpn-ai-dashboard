# ADR 002 — Frontend First

## Decision

The initial implementation prioritizes frontend prototype development with mock data.

## Reason

Building the UI first enables fast validation of mission control workflows and data model needs.

## Consequences

- The frontend structure is established before the backend is fully implemented.
- Mock data can be replaced later with real service-layer APIs.
- The team can refine requirements based on UI behavior.

## Status

Accepted
